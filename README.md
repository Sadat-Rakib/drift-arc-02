# DRIFT ARC 02

Responsive Three.js concept site with cinematic scroll, product finishes, engineering study, rhythm dashboard, and collection.

Deploy this static directory to Cloudflare Pages. The code imports Three.js r168 and Lenis from jsDelivr. No external GLB was supplied, so the wearable is constructed procedurally in Three.js. GLTFLoader and DRACOLoader are configured for the specified stack.
